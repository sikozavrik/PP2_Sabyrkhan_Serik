# Practice 2: Basic Python Concepts

This repository contains practical examples of basic Python concepts.

## Project Structure

* `boolean/` — Boolean data type, comparison operators, and logical operations.
* `if_else/` — Conditional statements (`if`, `else`, `elif`) and short-hand syntax.
* `loops/` — `while` and `for` loops, along with `break` and `continue` control statements.

## Usage

Each `.py` file can be executed individually using Python 3:
```bash
python boolean/boolean_intro.py
python if_else/if_statement.py
python loops/for_loop.py
